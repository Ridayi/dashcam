# 隨行錄：用舊 iPhone 當行車紀錄器

一個網頁 App，用 iPhone 的 Safari 開啟就能循環錄影，不需要上架 App Store。

## 功能

- 分段循環錄影（1 / 3 / 5 分鐘一段），空間滿了自動覆蓋最舊、沒鎖定的片段
- 鎖定事件：按「鎖定」或開啟撞擊偵測（G-sensor），前後約 30 秒的片段不會被覆蓋
- 影片上印日期時間，可加 GPS 車速與座標
- 每秒寫入一次，App 被關掉或手機摔到時，已錄的部分會在下次開啟時救回
- 被中斷（來電、螢幕鎖定）後回到畫面會自動繼續錄
- 片段可播放，並透過分享選單「儲存影片」到照片
- 熄屏模式：全黑畫面繼續錄（OLED 機型較省電）
- 可加入主畫面全螢幕使用，離線也能開

## 需求

- iOS 14.3 以上（建議 iOS 15 以上），用 Safari 開啟
- 必須是 https 網址（相機權限的要求）

## 使用前

1. 設定 › 螢幕顯示與亮度 › 自動鎖定 › 永不（螢幕一鎖，網頁就會停止錄影）
2. 接車充、避開陽光直射，iPhone 過熱時會關閉相機
3. 從控制中心關閉直向鎖定，手機橫放
4. Safari 分享按鈕 › 加入主畫面

## 已知限制

- 網頁不能在背景錄影，螢幕必須保持開啟、App 在最前面
- 影片存在瀏覽器的儲存空間裡；iOS 16 以前每個網站大約只能用 1 GB
- 從主畫面開啟和從 Safari 開啟的片段是分開存的
- 若錄出來全黑或卡頓，到設定關閉「時間浮水印」
- 若分享選單沒有「儲存影片」，改選「儲存到檔案」

## 本機測試

```
python -m http.server 8765 --directory dashcam
```

開啟 `http://localhost:8765/?demo&seg=8`：`demo` 使用模擬畫面代替相機，`seg=8` 讓每段只錄 8 秒。
